tri-trainer – Privacy Policy

tri-trainer is a private, self-hosted training assistant used by a single person (its developer). It is not offered to the public and has no other users.

Data accessed

With the user's consent, tri-trainer uses the Google Calendar API (scope calendar.events) to read and update events in two of the user's own calendars: a training calendar and a meal-plan calendar. Only meal-plan events are read from the meal-plan calendar; other events are ignored.

How data is used

Calendar data is used solely to plan the user's own training sessions and meals. It is never sold, shared with third parties, used for advertising, or used to train machine-learning models.

Storage and security

OAuth tokens and data are stored only on the user's own private server, in files readable only by the user. Nothing is stored on servers operated by the developer for others.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.

Google API Services User Data Policy

tri-trainer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
